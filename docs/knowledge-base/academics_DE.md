## faq-academics-001

### Question

Wie aktualisiere ich meine Adresse oder Telefonnummer?

### Answer

Der Registrar verfügt über offizielle Aktualisierungen der Studentenakten. Öffnen Sie https://portal.university.example/registrar/forms, wählen Sie „Studentendatenkorrektur“ aus, geben Sie die neue Adresse oder Telefonnummer ein, legen Sie alle erforderlichen Nachweise vor und senden Sie sie ab. Normalerweise aktualisiert der Registrar eine vollständige Anfrage innerhalb von fünf Werktagen.

### Escalation

Senden Sie eine E-Mail an registrar@university.example, wenn eine vollständige Anfrage nach fünf Werktagen noch aussteht.
