## faq-it-support-001

### Question

Ich habe mein Uni-Passwort vergessen.

### Answer

Öffnen Sie https://portal.university.example/support/it, wählen Sie „Passwort zurücksetzen“, geben Sie Ihre Universitäts-E-Mail-Adresse ein, führen Sie die Identitätsüberprüfung durch und befolgen Sie die Anweisungen zum Zurücksetzen. Anschließend melden Sie sich mit dem neuen Passwort im Studierendenportal unter https://portal.university.example an.

### Escalation

Senden Sie eine E-Mail an it-support@university.example, wenn die Identitätsüberprüfung oder das Zurücksetzen des Passworts fehlschlägt.

### Related phrasings

- Ich kann mich nicht anmelden
- Passwort vergessen
