## faq-registrar-054

Finance besitzt Studiengebühren und Zahlungen Dritter. ## faq-registrar-055

### Question

Wie melde ich einen ungewöhnlichen oder komplexen Aktenfall?

### Answer

Öffnen Sie https://portal.university.example/registrar/forms und wählen Sie Unusual Records Case aus. Beschreiben Sie den betroffenen Datensatz, die Bedingungen, das gewünschte Ergebnis, frühere Fallnummern, Fristen und unterstützende Dokumente. Geben Sie keine Passwörter oder nicht damit zusammenhängende medizinische Daten an. Der Registrar nimmt den Fall innerhalb von zwei Werktagen zur Kenntnis und gibt einen Zeitrahmen für die Prüfung bekannt, in der Regel innerhalb von zehn Werktagen.

### Escalation

Senden Sie eine E-Mail an registrar@university.example mit der Fallnummer, wenn es dringend ist oder innerhalb von zwei Werktagen keine Bestätigung eintrifft.
